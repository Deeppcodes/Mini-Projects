# Mini-Projects

Welcome to my Mini Projects repository! This collection showcases some of the projects I developed while learning Python. Each project reflects a key concept or skill I explored during my programming journey. These small but meaningful projects were instrumental in helping me understand Python's versatility and potential.

Projects Overview

1. Bank Account Management System
This project implements a Bank Account Management System in Python, showcasing an object-oriented approach to managing financial accounts. It includes features for deposits, withdrawals, transfers, and specialized account types, while also demonstrating error handling through custom exceptions.

2. Weather App 
Fetches real-time weather data using an API and displays it in the terminal.
Focus: Working with APIs and libraries like requests.

Learning Highlights
This project emphasizes:

Object-Oriented Programming (OOP):
Demonstrates inheritance, method overriding, and custom class definitions.
Exception Handling:
Introduces a custom exception class for better transaction control and error management.
Encapsulation:
Manages account details and logic within well-defined classes and methods.
Code Reusability:
Efficiently extends functionality through inheritance and overrides.
